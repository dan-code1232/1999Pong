# 1999Pong
Pong-like it is 1999!! Fully built in an emulator!
This is a 1 player pong game where you have to keep the ball alive as long as you can! 
Use wasd for the top bat and arrow keys for the bottom one. This was made entirely in game maker in the emulator for the hack club program!!
